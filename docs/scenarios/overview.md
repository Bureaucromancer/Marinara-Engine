# Scenarios

A **scenario** is a reusable seed: a setting, a supporting cast, and an opening. It is not a save file and not a story. You write it once and start it as many times as you like.

Open the Scenarios panel from the clapperboard button in the top bar.

## What a scenario holds

| Part | What it is for |
| --- | --- |
| **Setting** | The world itself — a name, a prose description, key locations, atmosphere, themes, and potential conflicts. This is the main content. |
| **Protagonist** | The played character: name, description, backstory, motivation, traits, appearance. Entirely optional — leaving it out is normal for a second-person scenario. |
| **Cast** | Supporting characters, each with a role, description, relationship, and traits. |
| **Opening** | The first message, plus any alternate greetings to pick between. |
| **Lorebooks** | Links to lorebooks that belong with this setting. |
| **Play hints** | Genre and content rating, which the game setup reads. Both default to unspecified. |

Everything is optional except the name.

## Writing a setting

The setting fields are meant to be filled in by hand. There is no generation step in this release — you write the world you want, and nothing rewrites it behind you.

If you would rather sketch, write a short description and come back to it. Nothing else depends on the setting being finished.

## Organising

- **Favourites** — the star on each row, filterable from the panel.
- **Tags** — free-form, shared with the tag shelf above the list.
- **Folders** — drag scenarios onto a folder to group them. Folders are per-browser and are not shared between devices.

## What scenarios do not do yet

Nothing consumes a scenario in this release. They are stored, edited, imported and exported, but starting a chat or a game from one comes later. Everything you write now is kept.

See also: [Import and export](import-export.md).
